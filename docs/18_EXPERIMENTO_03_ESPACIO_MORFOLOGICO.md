# Experimento 03 — Espacio morfológico

## Propósito
Comprobar si las características extraídas de las máscaras pueden combinarse en una representación multivariable estable y visualizable.

## Procedimiento
1. Auditar el dataset.
2. Seleccionar variables según el protocolo.
3. Separar variables dependientes de escala de variables adimensionales.
4. Estandarizar dentro del conjunto analítico.
5. Ejecutar PCA como herramienta exploratoria.
6. Calcular una matriz de distancias normalizadas.
7. Verificar sensibilidad eliminando variables redundantes.

## Interpretación
PCA es exploratorio. Una separación visual de grupos no demuestra por sí sola una diferencia biológica ni permite afirmar clasificación perfecta.

Las distancias se consideran provisionales hasta evaluar robustez, dependencia entre variables y generalización a datos no utilizados para definir el procedimiento.

## Resultado que buscamos
Una representación de cada observación como un punto en un espacio de características, acompañada por evidencia de estabilidad y un registro reproducible de las decisiones.
