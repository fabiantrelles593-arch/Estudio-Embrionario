# Procedimiento de auditoría del dataset

Antes de cualquier análisis biológico, el programa revisa:

- presencia de campos obligatorios;
- identificadores duplicados;
- etapas fuera de CS12–CS18;
- número de especímenes independientes;
- especímenes con múltiples imágenes;
- estados de calidad;
- permisos/licencias pendientes.

Un dataset puede tener advertencias y aun así ser procesable, pero ninguna observación con procedencia o permisos sin resolver debe considerarse automáticamente parte del conjunto definitivo.
