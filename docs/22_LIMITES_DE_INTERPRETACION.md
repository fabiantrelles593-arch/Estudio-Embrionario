# Límites de interpretación

- Las figuras de demostración son sintéticas, no imágenes de embriones humanos.
- El valor `stage` de la demostración sirve únicamente para ejercitar la validación del formato; no representa clasificación biológica real.
- La auditoría requiere los campos de procedencia, espécimen, imagen, etapa, modalidad, vista, fuente, identificador del activo, estado de uso, método de segmentación y calidad.
- `license_status` debe declarar un estado de uso verificado. Valores pendientes, desconocidos o restringidos impiden que el dataset sea marcado como válido.
- Una imagen de un mismo espécimen no debe considerarse automáticamente un individuo independiente.
- Los descriptores basados en la componente principal se reportan explícitamente como tales; área y perímetro resumen todas las componentes.
- El código no emite diagnósticos ni confirma hipótesis biológicas.
